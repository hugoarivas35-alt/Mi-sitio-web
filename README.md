# Proyecto Web HTML5 - BMW

Este es mi sitio web sobre la marca BMW, hecho para Lenguaje de Marcas. Es una web de 5 páginas hechas únicamente con HTML básico, tal como se nos ha pedido en clase, para usar la estructura de las etiquetas, enlaces, listas, tablas, galerías multimedia y formularios.

## Estructura del proyecto
- `index.html`: Página de inicio donde presento la web, la historia de la marca y un resumen de las distintas secciones.
- `blog.html`: Un artículo del blog centrado en los orígenes de la marca y el cambio hacia los coches eléctricos.
- `tabla.html`: Página con una tabla comparativa sobre especificaciones de varios modelos de BMW.
- `galeria.html`: Galería con fotos, el sonido de los motores, un vídeo de YouTube y la ubicación de la sede de Múnich en Google Maps.
- `formulario.html`: Formulario de contacto con varios tipos de campos para mandar dudas o suscribirse.
- `rss.xml`: Archivo XML con el canal RSS para seguir las publicaciones del sitio.

## Tecnologías utilizadas
- HTML5 (estructura básica sin CSS)
- XML para el canal RSS
- Git y GitHub para guardar los cambios
- GitHub Pages para publicar la web

## Características principales
- Navegación entre 5 páginas conectadas con un menú arriba.
- Uso de etiquetas semánticas de HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`).
- Tabla completa organizada con encabezado, cuerpo, pie y metidas en celdas (`scope`).
- Elementos multimedia puestos mediante iFrame de YouTube y Google Maps.
- Formulario dividido por temáticas con etiquetas `fieldset` e `input` variados.
- Sindicación mediante el archivo `rss.xml`.

## Dificultades encontradas
1. **Rutas relativas entre páginas:** Al principio me liaba un poco al enlazar las distintas páginas entre sí, pero lo solucioné asegurándome de que todas estuvieran en la misma carpeta raíz.
2. **Estructura correcta de la tabla:** Me costó recordar para qué servía cada etiqueta de la tabla (`thead`, `tbody`, `th`), pero revisando los apuntes conseguí estructurarla bien.
3. **Ajuste de los vídeos y el mapa:** Ajustar el tamaño de los iFrame de YouTube y Maps para que no se vieran descuadrados en pantalla sin usar estilos CSS avanzados.

## Decisiones técnicas
- He mantenido el HTML prpio y limpio para cumplir con la norma de la práctica de no meter CSS.
- Usé la misma estructura de cabecera, navegación y pie de página en los 5 archivos para que tuviera también coherencia.
- Elegí imágenes reales de BMW de buena calidad para que la página tuviera mejor aspecto.
